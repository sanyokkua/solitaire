How to play

A→K
Fill the four foundations

Each suit goes home in order, Ace first, King last. Move all 52 cards to win.

R/B
Build down, alternate colours

On the table, place a card on one rank higher of the opposite colour: red 9 on black 10.

K
Only Kings fill an empty column

Move whole face-up runs at once; a hidden card flips when it's uncovered.

1|3
Draw from the stock

Draw 1 turns one card at a time. Draw 3 turns three, and only the top one plays.

Scoring

Standard: +10 to a foundation, +5 waste to table, +5 per card turned over, −2 every 10 s, −100 per redeal in Draw 1. Vegas: start at −$52, win $5 per card home, three passes through the deck.

Statistics

Kept only in this browser. The full build stores stats and the game in progress in IndexedDB.

What this mockup shows

Everything marked Working runs in this single page. Full build items are the next steps from the research plan.

  • WorkingRules engine, kept apart from the UI

    Fisher–Yates shuffle seeded by crypto.getRandomValues; legal-move checks, win detection, stuck detection.

  • WorkingWinnable Draw 1 deals

    Bounded depth-first solver (visited-state set, safe auto-moves, 5,000-node cap). Deals it can't prove are thrown away and reshuffled — usually 1–2 tries.

  • WorkingTap, drag, keyboard

    Pointer Events drag with a movement threshold, drop by overlap, smart-tap and select-and-place, double-click home, shortcuts.

  • WorkingUndo / redo, hints, auto-finish

    Immutable snapshots for history; hints rank moves that reveal cards; auto-finish unlocks when every card is face up.

  • WorkingStandard and Vegas scoring, daily deal

    Pass limits, time penalty, win bonus; the daily deal is seeded from the date so everyone gets the same one.

  • WorkingMotion that respects the player

    Deal, flip, move and win cascade animate transform only; all of it turns off with reduced motion.

  • Full buildReact + TypeScript + Zustand, dnd-kit, Motion

    Same structure as Minesweeper: pure game/ module, store, screens, tests in Vitest and Playwright.

  • Full buildSolver in a Web Worker, Draw 3 verification

    Moves the search off the main thread and adds an ordered-talon search for Draw 3.

  • Full buildPWA, IndexedDB, Capacitor

    Installable and fully offline via vite-plugin-pwa; optional iOS/Android shells from the same build.
